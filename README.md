# Lifesim

A deep, grounded, text-based life simulator: one person's life in the United States from birth to
death, then on through their children. Browser app in TypeScript with no backend.

**Status:** design phase. No game code yet.

- [Design document](docs/DESIGN.md) — state model, systems, causal map, time and event models, data
  formats, calibration targets, technical decisions and open questions.
